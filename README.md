# ⚡ 관동지방 1세대 포켓몬 도감 (Pokédex Gen 1)

모던하고 세련된 카드 UI와 실시간 검색/필터링, 6마리 나만의 파티 빌더, 포켓몬 울음소리 재생, 상세 종족값 차트 및 타입 상성 분석을 제공하는 **1세대 151마리 완전 한국어 포켓몬 도감 웹 애플리케이션**입니다.

---

## 🌟 주요 기능 (Features)

1. **관동지방 1세대 151마리 완전 한국어 데이터 지원**:
   - 1번 이상해씨부터 151번 뮤까지 한국어 이름, 영문명, 도감 번호, 분류(씨앗포켓몬 등), 신장, 체중, 공식 플레이버 도감 텍스트 수록.
   - 고해상도 공식 2D 일러스트(Official Artwork) 및 5세대 블랙/화이트 도트 애니메이션 스프라이트(GIF) 지원.
   - 공식 포켓몬 울음소리(Cry) 오디오 실시간 재생.

2. **다양한 검색 및 정렬/필터링 기능**:
   - **실시간 검색**: 한국어 이름("피카츄"), 영문명("Pikachu"), 도감 번호("25", "#025") 즉시 검색.
   - **18개 타입 필터**: 노말, 불꽃, 물, 풀, 전기, 얼음, 격투, 독, 땅, 비행, 에스퍼, 벌레, 바위, 고스트, 드래곤, 강철, 페어리, 악 필터 칩.
   - **다양한 정렬**: 번호순(오름차순/내림차순), 이름순(가나다순), 종족값 총합순(강함순), HP/공격/방어/스피드 개별 능력치순.

3. **심층 상세 스펙 모달 (Detail Modal)**:
   - 공식 일러스트 ↔ 도트 애니메이션 전환 뷰.
   - 6가지 종족값(HP, 공격, 방어, 특수공격, 특수방어, 스피드) 및 총합 시각화 프로그레스 바.
   - **타입 상성표 (Damage Effectiveness)**: 2배~4배 약점, 0.5배~0.25배 내성, 0배 무효 피해 자동 계산 및 뱃지 표시.
   - **진화 계통도 (Evolution Tree)**: 진화 단계별 카드 표시 및 클릭 시 해당 포켓몬으로 즉시 이동.
   - 키보드 네비게이션: `←` / `→` 화살표 키로 이전/다음 포켓몬 탐색 및 `ESC` 닫기 지원.

4. **나만의 포켓몬 파티 (6마리 Team Builder)**:
   - 최대 6마리의 포켓몬을 나만의 배틀 파티로 구성 및 로컬 스토리지 자동 저장.
   - **파티 종합 분석(Team Analytics)**:
     - 파티 평균 종족값 계산
     - 파티가 보유한 타입 커버리지 분석
     - **공통 약점 경고(Common Weakness Alert)**: 파티 내 3마리 이상이 공유하는 취약 타입 자동 탐지.
   - 원클릭 팀 구성 텍스트 클립보드 복사(Share).

5. **즐겨찾기 (Favorites)**:
   - 하트 아이콘 클릭으로 손쉽게 찜하기 및 즐겨찾기 필터 모아보기.
   - 브라우저 LocalStorage에 영구 보존.

## 🚀 즉시 실행 방법 (Quick Start)

본 프로젝트는 복잡한 설치나 빌드 과정 없이 **웹 브라우저(Chrome, Edge, Whale 등)만 있으면 즉시 실행**할 수 있습니다.

### 방법 1. 원클릭 실행 (가장 추천)
- 폴더에 있는 **`open-pokedex.bat`** 파일을 더블 클릭합니다.
- 기본 브라우저에서 포켓몬 도감이 즉시 열립니다!

### 방법 2. 직접 열기
- **`index.html`** 파일을 더블 클릭하거나, 열려 있는 웹 브라우저 창으로 드래그 앤 드롭합니다.

## 💻 Vite + React + TypeScript 환경에서 실행 시 (선택 사항)

Node.js 환경이 설치되어 있는 경우 표준 번들러 환경으로도 실행할 수 있습니다:

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 배포용 빌드
npm run build
```
